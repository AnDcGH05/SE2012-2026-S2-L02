\# Student Management System using Classes, Packages \& Control Structures



\## Description



A simple Student Management System developed using Java for SE2012 (OOAD) Practical 2.



\## Options



\* Add Student

\* Add Course

\* List Students

\* Search Student

\* Sort Students



\## How to Run

Run the following command from the root directory:



```cmd

git clone https://github.com/AnDcGH05/SE2012-2026-S2-L02.git

cd StudentManagement

javac models/\*.java services/\*.java mainapp/\*.java

java mainapp.Main

```



\## How to Generate Javadoc

Generate documentation using:



```cmd

javadoc -d docs models/\*.java services/\*.java mainapp/\*.java

```
